# KUH-1 표준화평가 암기카드

- 웹 앱: `index.html` (암기카드), `exam.html` (문제안 B~E안 실전 시험)
- 안드로이드 앱: `android/` 폴더. `index.html`을 고쳐서 올리면 GitHub이 APK를 자동으로 만들어 **Releases**에 올립니다.

## 휴대폰에 설치하는 방법

**APK로 설치 (안드로이드)**
1. 저장소 오른쪽의 **Releases** → 가장 위 버전 → `KUH1_암기카드.apk` 내려받기
2. "출처를 알 수 없는 앱 설치" 허용 후 설치

**웹 앱으로 설치 (안드로이드·아이폰, GitHub Pages를 켠 경우)**
1. `https://<아이디>.github.io/<저장소이름>/` 접속
2. 크롬: ⋮ → **홈 화면에 추가** / 사파리: 공유 → **홈 화면에 추가**

## 내용을 고칠 때

- `index.html`을 새 파일로 교체해 올리면 APK가 자동으로 다시 만들어집니다 (약 5분, **Actions** 탭에서 진행 상황 확인).
- 웹 앱을 쓰는 경우 `sw.js`의 `VERSION` 숫자(v1 → v2)를 올리면 휴대폰에 새 버전이 바로 반영됩니다.
- `android/kuh1.keystore`는 지우거나 바꾸지 마세요. 바뀌면 업데이트 설치가 안 되고 앱을 지웠다가 다시 깔아야 합니다(진도 사라짐).
- 진도와 메모는 각 기기에 저장됩니다.
